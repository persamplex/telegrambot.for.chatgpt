# ربات تلگرام برای ChatGPT

یک درگاه HTTP ساده و یک‌طرفه روی Cloudflare Workers برای ارسال پیام متنی از دستیار هوش مصنوعی یا کلاینت مجاز به گفتگوی ثابت ادمین از طریق ربات شخصی تلگرام. دریافت پیام، وب‌هوک، دیتابیس و تاریخچه گفتگو ندارد.

## نصب
۱. با BotFather ربات بسازید، گفتگو با ربات را آغاز کنید و شناسه عددی گفتگوی خود را به دست آورید (مثلاً با API خصوصی getUpdates تلگرام).
۲. یک Worker بسازید و محتوای worker.js را در ویرایشگر آن کپی کنید.
۳. در نسخه خصوصی فایل، مقادیر نمونه TELEGRAM_BOT_TOKEN، ADMIN_CHAT_ID و API_KEY را جایگزین کنید. کلید API طولانی و تصادفی باشد.
۴. ورکر را منتشر کنید و آدرس HTTPS آن را بردارید.

اطلاعات واقعی را در گیت‌هاب یا پرامپت منتشر نکنید. تنظیمات درون فایل برای نصب ساده است؛ برای محیط عملیاتی Cloudflare Secrets امن‌تر است. کلید افشاشده را تعویض کنید.

## API
درخواست POST به مسیر /send با هدر Authorization: Bearer YOUR_API_KEY و Content-Type: application/json.
بدنه: {"text":"سلام از ChatGPT"}
مقصد ثابت است و درخواست نمی‌تواند آن را تغییر دهد. متن نباید خالی یا بیشتر از ۴۰۹۶ واحد UTF-16 باشد.

```sh
curl -X POST https://YOUR-WORKER.workers.dev/send \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"text":"سلام از ChatGPT"}'
```

موفقیت: HTTP 200 و {"ok":true}. خطاها با ok:false و کد خطا برمی‌گردند. پذیرش پیام توسط تلگرام به معنی خوانده شدن آن نیست.

## نمونه پرامپت اسکیل
```text
یک درگاه یک‌طرفه ارسال پیام تلگرام در https://YOUR-WORKER.workers.dev/send داری.
وقتی کاربر ارسال پیام را مجاز کرد، با ابزار HTTP موجود درخواست POST با بدنه JSON {"text":"متن پیام"} و هدر Content-Type: application/json و Authorization: Bearer <کلید امن تنظیم‌شده> بفرست.
مقصد را تغییر نده، کلیدها را افشا نکن و بدون مجوز پیام نفرست. فقط با دریافت HTTP 200 و ok:true موفقیت را اعلام کن. ادعای خواندن پیام تلگرام نکن و خطاهای مبهم را کورکورانه تکرار نکن.
اگر ابزار HTTP نداری، محدودیت را توضیح بده.
```
کلید را در تنظیمات امن ابزار قرار دهید، نه متن گفتگو. پرامپت به‌تنهایی دسترسی شبکه نمی‌دهد؛ ابزار HTTP سازگار یا GPT Action تنظیم‌شده لازم است.
